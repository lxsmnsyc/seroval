# Security Policy

## Supported Versions

Currently, seroval's versioning is linear so the only supported version is the latest version.

## Reporting a Vulnerability

If you think there's a vulnerability issue with seroval, [please submit a draft security advisory](https://github.com/lxsmnsyc/seroval/security/advisories/new).

Security advisories must include
- the summary of the issue
- the specificities of the problem
- minimal reproduction
- a proposed solution

Once the vulnerability has been confirmed, the maintainer will release a fix as-soon-as-possible, and the advisory will be published at least one month after the confirmation.
