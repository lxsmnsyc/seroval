title: SRV016

---

- **Error**: `SerovalDeserializationError`
- **Step**: `deserialize`
- **Fields**: `cause`, the error that was thrown.

## What it means

An error that does not come from seroval was thrown while seroval built the value. Seroval wraps it in `SerovalDeserializationError` and keeps it in `cause`. When the wrapped error is a seroval error, the wrapper takes the code of that error instead of SRV016.

## Common causes

- The `deserialize` function of a plugin throws.
- A constructor rejects a value from the input, for example a `Temporal` string that does not parse.

## How to fix it

- Read the `cause` field. Its name and message say what failed.
- Fix the code that threw. If it is in seroval, [open an issue](https://github.com/lxsmnsyc/seroval/issues/new).
