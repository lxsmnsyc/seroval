- **Error**: `RangeError`
- **Step**: none
- **Fields**: only `code`. This is a standard `RangeError`, because the cause is how the function is called, not the data.

## What it means

The `maxBase64Length` option is not a non-negative safe integer.

## Common causes

- A negative number, a fraction, `NaN` or `Infinity`.
- A string read from configuration, such as `"1000000"`.

## How to fix it

- Pass a whole number from `0` to `Number.MAX_SAFE_INTEGER`, or leave the option out to use the default of `1000000`. See [JSON decoding limits](../binary-data.md#json-decoding-limits).
