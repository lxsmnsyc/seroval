---
title: SRV013
description: A plugin value failed its validator.
---

- **Error**: `SerovalPluginValidationError`
- **Step**: `deserialize`
- **Fields**: `tag`, the tag of the plugin, and `field`, the name of the field that failed.

## What it means

The [`validate`](../plugin-security.md#validate-every-value) function of a plugin rejected a field of its node before the plugin built the value.

## Common causes

- The input was not produced by seroval, or was changed on the way.
- The sending and the receiving side use different versions of the plugin.
- Someone sent the input on purpose to attack the receiver.

## How to fix it

- Use the same plugin versions on both sides.
- Treat the input as untrusted and drop it.
- If you wrote the plugin, check that `validate` accepts every value that its `parse` produces.
