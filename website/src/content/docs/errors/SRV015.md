---
title: SRV015
description: The serializer failed with an error that is not from seroval.
---

- **Error**: `SerovalSerializationError`
- **Step**: `serialize`
- **Fields**: `cause`, the error that was thrown.

## What it means

An error that does not come from seroval was thrown while seroval wrote the output. Seroval wraps it in `SerovalSerializationError` and keeps it in `cause`. When the wrapped error is a seroval error, the wrapper takes the code of that error instead of SRV015.

## Common causes

- The `serialize` function of a plugin throws.

## How to fix it

- Read the `cause` field. Its name and message say what failed.
- Fix the code that threw. If it is in seroval, [open an issue](https://github.com/lxsmnsyc/seroval/issues/new).
