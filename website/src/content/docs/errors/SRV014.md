title: SRV014
description: The parser failed with an error that is not from seroval.

---

- **Error**: `SerovalParserError`
- **Step**: `parse`
- **Fields**: `cause`, the error that was thrown.

## What it means

An error that does not come from seroval was thrown while seroval read the value. Seroval wraps it in `SerovalParserError` and keeps it in `cause`. When the wrapped error is a seroval error, the wrapper takes the code of that error instead of SRV014.

## Common causes

- A getter on the value throws.
- A `Proxy` in the value throws from one of its traps.
- The `test` or `parse` function of a plugin throws.

## How to fix it

- Read the `cause` field. Its name and message say what failed.
- Fix the code that threw. If it is in seroval, [open an issue](https://github.com/lxsmnsyc/seroval/issues/new).
