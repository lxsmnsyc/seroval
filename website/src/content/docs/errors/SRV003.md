title: SRV003
description: A plugin for a tag is missing.
type: reference
---

- **Error**: `SerovalMissingPluginError`
- **Step**: `serialize` or `deserialize`
- **Fields**: `tag`, the tag of the plugin that is missing.

## What it means

The input has a plugin node, and no plugin in the `plugins` option has its tag.

## Common causes

- The receiver passes fewer plugins than the sender.
- A plugin was renamed, so its tag differs between the two sides.
- The input was not produced by seroval, or was changed on the way.

## How to fix it

- Pass the same plugins to the sending and the receiving functions. See [using plugins](../using-plugins.md).
- Use the same version of each plugin package on both sides.
