---
title: SRV007
description: A typed array name is unknown.
---

- **Error**: `SerovalUnknownTypedArrayError`
- **Step**: `deserialize`
- **Fields**: none. Development builds name the typed array in the message.

## What it means

A typed array node names a constructor that seroval does not know.

## Common causes

- The input was not produced by seroval, or was changed on the way.
- The input was produced by a newer seroval version that supports more typed arrays.

## How to fix it

- Use the same seroval version on both sides.
- Check that the input reaches the receiver unchanged.
