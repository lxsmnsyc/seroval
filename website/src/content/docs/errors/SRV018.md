---
title: SRV018
description: The stream parser has no output callback.
type: reference
---

- **Error**: `SerovalStreamOutputError`
- **Step**: `parse`
- **Fields**: none.

## What it means

The stream parser tried to emit a node after its output callback was removed. Seroval removes the callback when the stream stops, and emits no node after that. This code means that check failed.

## Common causes

- A bug in seroval.

## How to fix it

- [Open an issue](https://github.com/lxsmnsyc/seroval/issues/new) with the value you sent and the order of your calls.
