title: SRV017
description: A stream already has a consumer.
type: reference

- **Error**: `SerovalStreamConsumedError`
- **Step**: none
- **Fields**: none.

## What it means

A received live stream got a second listener. A received [live stream](../streams-and-iterables.md#live-streams) keeps its values only until the first listener subscribes. A second listener would miss them.

## Common causes

- Two parts of the code subscribe to the same received stream.
- The received stream is serialized again while something else reads it.

## How to fix it

- Subscribe once, and pass the values on from that listener.
- Send a stream from `createStream` instead if many readers need every value.
