---
title: SRV020
description: An ArrayBuffer is larger than maxBase64Length.
type: reference
---

- **Error**: `SerovalBase64LimitError`
- **Step**: `deserialize`
- **Fields**: `limit`, the `maxBase64Length` in effect.

## What it means

An `ArrayBuffer` in the input is encoded as a base64 string longer than the `maxBase64Length` option. The default is `1000000` characters, about 750 kB of data.

## Common causes

- The data holds a large binary value, such as a file or an image.
- Input built on purpose to make the receiver allocate a large buffer.

## How to fix it

- Raise `maxBase64Length` on the receiver if large buffers are expected. See [JSON decoding limits](../binary-data.md#json-decoding-limits).
- Send large files another way, for example as a separate download.
