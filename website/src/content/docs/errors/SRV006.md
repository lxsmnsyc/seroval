- **Error**: `SerovalMissingReferenceForIdError`
- **Step**: `deserialize`
- **Fields**: none. Development builds name the key in the message.

## What it means

The input refers to a [`createReference`](../isomorphic-references.md) key, and the receiver has no value registered under that key.

## Common causes

- The receiver never calls `createReference` for that key.
- The receiver calls `createReference` after it decodes the input.
- The key differs between the two sides.

## How to fix it

- Call `createReference` with the same key on both sides, in a module that runs before the input is decoded.
