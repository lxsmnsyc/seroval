- **Error**: `SerovalMissingReferenceError`
- **Step**: `parse`
- **Fields**: `value`, the value that has no reference.

## What it means

This code belongs to a deprecated class. Seroval no longer throws it. The class stays exported so older `instanceof` checks keep working.

## Common causes

- Code of your own, or an old plugin, that still creates `SerovalMissingReferenceError`.

## How to fix it

- Check for [SRV006](./SRV006.md) instead. Seroval throws SRV006 when a reference key is missing.
